## What is CommitT?

CommitT is a **self-binding accountability system** that makes your commitments enforceable through technology. Unlike traditional to-do apps that rely on willpower, CommitT uses:

- **Hardware-Level App Blocking** — A native Android Accessibility Service that intercepts app launches and blocks access to distracting applications during commitment windows.
- **Real-Time Location Enforcement** — 1Hz GPS streams from the Android LocationManager verify you are physically present at your committed location.
- **Real Penalties** — Configurable consequences (public photo posting, monetary loss) that execute automatically if you fail your commitment.
- **Waiver Challenges** — A second-chance system where you can earn forgiveness by completing CAPTCHA challenges before a deadline timer expires.

## Tech Stack

| Layer | Technology |
|---|---|
| **Mobile** | React Native, Expo, TypeScript, Reanimated, Zustand |
| **Native Android** | Kotlin, Accessibility Service, WindowManager, AlarmManager |
| **Backend** | Convex (real-time sync + serverless mutations) |
| **Local DB** | SQLite via Expo SQLite (WAL journaling, Nuke & Pave migrations) |
| **Auth** | Better Auth (Email + Google OAuth) |
| **Desktop** | Tauri + Vite + React |
| **Browser Extension** | WXT Framework |
| **Monorepo** | Turborepo + Bun |
