# App Lister Module

React Native and Expo do not provide built-in APIs for querying the device's installed application list. To support the "Digital Commitment" feature, CommitT uses a custom Kotlin module to interface directly with the Android `PackageManager`.

## Core Functionality

The `AppListerModule` exposes a single asynchronous function `getInstalledApps()` to the JavaScript layer. 

It returns:
*   Human-readable app names.
*   Unique Package IDs.
*   Base64-encoded PNG icons.

### Smart Filtering
The module avoids dumping hundreds of useless system services by filtering via `getLaunchIntentForPackage()`. If an app cannot be manually opened by a user from the launcher (e.g., hidden background daemons), it is excluded from the blocklist options, keeping the UI clean and performant.

### Memory Optimization
To prevent Out-Of-Memory (OOM) crashes when extracting 300+ apps, the native layer rasterizes the `BitmapDrawable` vectors and scales all icons down to a strict 100x100 pixel grid. This keeps the Base64 payloads small (~10KB each) and safe for React Native bridge transit.
