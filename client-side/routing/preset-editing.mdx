# Preset Editing

The (edit-preset) route group contains screens for creating, editing, and deleting presets. Presets are reusable configurations that can be attached to time slots with a single tap.

---

## Preset Types

| Type | File | Data Stored |
| :--- | :--- | :--- |
| **Location** | edit-location-preset.tsx | GPS coordinates, radius, address, name |
| **Digital (Blocklist)** | edit-digital-preset.tsx | App package names, website URLs, preset name |
| **Rule** | edit-rule-preset.tsx | Verification style, alarm timing, grace period, intensity |

---

## Location Preset Editor

The most complex preset editor (~400 lines). Integrates Google Maps with:

- Full-screen map view with draggable pin
- Address search via Google Places API (search-preset-location.tsx sub-screen)
- Radius slider for geofence configuration
- Name input for preset identification

---

## Isolated State

Preset editing uses usePresetEditStore -- a separate Zustand store that is completely isolated from the main usePresetStore and useTaskDraftStore. This ensures that editing a preset does not affect any in-progress wizard flow.

---

## Persistence

On save, presets are written directly to the Convex backend. The usePresetStore is then re-hydrated on the next wizard layout mount via usePresetHydration().
