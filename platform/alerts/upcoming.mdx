# Upcoming Alerts

The **Upcoming** sub-tab within the Alerts section displays a chronological list of all pending task instances that have not yet been verified. This provides a forward-looking agenda view, distinct from the calendar's grid layout.

---

## What is Displayed

Each upcoming alert card surfaces:

| Field | Description |
| :--- | :--- |
| **Task Name** | The parent commitment title |
| **Scheduled Time** | Start and end time of the instance |
| **Location** | Attached location name and address (if applicable) |
| **Time Remaining** | Relative countdown to the verification window |
| **Conditions** | Icons indicating which enforcement conditions are active |

---

## Sorting and Filtering

Alerts are sorted in strict chronological order — the nearest pending instance appears at the top. Past instances that were never verified are excluded from this view (they appear in the Verified sub-tab as failures).

---

## Example

> The Upcoming tab at 4:00 PM on a Wednesday shows:
>
> 1. **Library Focus** — Today, 5:00 PM – 9:00 PM — University Library — In 1 hour
> 2. **Morning Gym** — Tomorrow, 6:00 AM – 8:00 AM — Fitty Gym VIT — In 14 hours
> 3. **Swimming** — Saturday, 9:00 AM – 11:00 AM — VIT Sports Complex — In 3 days
