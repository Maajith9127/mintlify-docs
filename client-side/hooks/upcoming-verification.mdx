# useUpcomingVerification

The useUpcomingVerification hook (hooks/commits/useUpcomingVerification.ts) computes the next pending verification instance and makes it available to the Dashboard's upcoming card.

---

## Query Logic

The hook queries 	ask_instances from SQLite where:
- status = 'pending'
- start_time > Date.now()
- Ordered by start_time ASC
- Limited to 1 result

The result is consumed by the Dashboard to display a countdown timer and quick-access button.
