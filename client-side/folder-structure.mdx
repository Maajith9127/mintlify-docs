## How to Read This Tree

Each file or directory in the tree above is annotated with an arrow (→) pointing to its corresponding documentation page in this guide. The tree is organized by **responsibility domain**:

| Domain | Directory | Doc Section |
| :--- | :--- | :--- |
| **Screens** | app/ | Routing and Screens |
| **State** | stores/ | State Management |
| **Infrastructure** | lib/ | Core Infrastructure |
| **Hooks** | hooks/ | Hooks |
| **Components** | components/ | Components |
| **Providers** | providers/, contexts/ | Providers and Contexts |
| **Native** | modules/ | Native Modules (separate guide) |
