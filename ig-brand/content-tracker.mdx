## 🔁 The Weekly Scraping Loop

**Checklist for every Sunday:**
- [ ] Run Apify scraper on the competitor list
- [ ] Drop new CSV data into `competitor_data.csv`
- [ ] Run the Python extraction script to calculate new outliers
- [ ] Review `competitors.mdx` for the new top 3 outliers per account
- [ ] Script the next 21 posts (3/day for 7 days) based on the new outliers
